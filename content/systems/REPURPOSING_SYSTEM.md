# Valfin Tech — Content Repurposing System (Phase 4)
**Version 1.0 | Created 2026-06-13**
**Governed by:** [`docs/CONTENT_BRAND_GUIDELINES.md`](../../docs/CONTENT_BRAND_GUIDELINES.md)

> **The principle:** Create once, publish everywhere. One approved video should become a week's worth of content across formats — without re-inventing the message each time. This document is the repeatable system (and the reusable templates) for turning a single source video into 7+ derivative assets.

---

## 1. The Repurposing Map

Every approved source video flows into these outputs:

```
            ┌──────────────────────────┐
            │   1 APPROVED SOURCE VIDEO │
            │   (from /production)      │
            └────────────┬─────────────┘
                         │
   ┌─────────────┬───────┼────────┬─────────────┬──────────────┐
   ▼             ▼       ▼        ▼             ▼              ▼
IG Reel      TikTok   YT Short  LinkedIn     Carousel       Blog
(native)     (native) (native)  post+video   (5–8 slides)   (600–900w)
                                                              │
                                                              ▼
                                                      Email newsletter
                                                      (1 section)
```

**From one source video you produce, at minimum:**
1. Instagram Reel (native upload + caption + hashtags)
2. TikTok (native re-upload, no IG watermark, native caption)
3. YouTube Short (native upload + description)
4. LinkedIn post (text adaptation, optionally with the video)
5. Instagram/LinkedIn Carousel (5–8 slides)
6. Blog article (600–900 words)
7. Email newsletter section (1 short section, links to the video/blog)

Most of these are **already pre-written inside each production package** (IG caption, hashtags, LinkedIn adaptation, TikTok description, YT description). This system covers the formats packages don't include (carousel, blog, email) and the workflow to assemble them fast.

---

## 2. The Golden Rules of Repurposing

1. **One core message per source.** Every derivative says the same one thing in a format-native way. Don't drift the message.
2. **Re-native, don't cross-post.** Never post an IG video with the watermark to TikTok. Re-upload clean. Re-write captions per platform's voice (LinkedIn ≠ TikTok).
3. **Hook stays; format changes.** The hook is the asset. Keep it consistent across formats; change only the wrapping.
4. **Brand rules apply to every derivative.** Run each one against the [approval checklist](../checklists/CONTENT_APPROVAL_CHECKLIST.md) — a banned word can sneak in during a rewrite.
5. **One CTA per derivative**, matched to the funnel stage of the source.

---

## 3. Platform Voice Cheat-Sheet (for rewriting)

| Platform | Voice shift | Length | CTA placement | Hashtags |
|---|---|---|---|---|
| **Instagram** | Warm, relatable, conversational | 80–150 words | End of caption | 8–12, mixed reach |
| **TikTok** | Casual, raw, fast, founder-forward | 1–2 lines | In caption, lighter | 3–5, broad |
| **YouTube Shorts** | Slightly more educational/evergreen | 1–3 lines + link | First line + description | 0–3 in description |
| **LinkedIn** | Professional, lesson-driven, no slang | 100–250 words | Soft, end of post | 0–3, optional |
| **Carousel** | Punchy, one idea per slide | 5–8 slides | Final slide | In caption |
| **Blog** | Educational, scannable, SEO-aware | 600–900 words | Mid + end | n/a |
| **Email** | Personal, 1:1, founder voice | 120–200 words | One button/link | n/a |

## 4. TEMPLATE — Carousel (5–8 slides)

> Carousels turn any video into a saveable, swipeable asset. Great for "myth," "list," and "how it works" ideas. Use the template in [`../templates/CAROUSEL_TEMPLATE.md`](../templates/CAROUSEL_TEMPLATE.md).

**Structure:**
- **Slide 1 (Hook):** The video's hook, big and bold. Make them swipe.
- **Slide 2 (Stakes/Problem):** Name the pain or the cost.
- **Slides 3–6 (Body):** One idea per slide. For a list idea, one item per slide. For a story, one beat per slide.
- **Slide 7 (Reframe/Payoff):** The "so here's the truth" turn.
- **Slide 8 (CTA):** One ask. Calculator or follow.

**Worked example — from PKG-005 (The 30 Seconds After Someone Calls):**
1. "What should happen in the 30 seconds after a customer reaches out"
2. "Right now, for most businesses? It depends on whether someone's free. That's the leak."
3. "1. Caught — every call, text, and form. Nothing slips."
4. "2. Replied — a real, friendly message in your voice. In seconds."
5. "3. Followed up — Day 1, Day 3, Day 7. Stops when they book."
6. "4. Booked — the ready ones land on your calendar."
7. "All of it runs whether you're on a roof or asleep."
8. "See how it works → link in bio"

## 5. TEMPLATE — Blog Article (600–900 words)

> Blogs give the message an SEO home and an evergreen link for email/DMs. Use [`../templates/BLOG_ARTICLE_TEMPLATE.md`](../templates/BLOG_ARTICLE_TEMPLATE.md).

**Structure:**
1. **H1 / Title** — the hook, expanded into a searchable headline (include a keyword like "missed calls," "follow up with leads," "speed to lead").
2. **Opening (100w)** — the relatable scenario from the video, in prose.
3. **The real problem (150w)** — name it, size it (honest/hypothetical framing only).
4. **Why it happens (150w)** — non-judgmental; structural reasons (you're on a job, leads scatter).
5. **What "fixed" looks like (200w)** — the four stages in plain language, outcome-first.
6. **The honest part (100w)** — proof standard: what we can and can't claim yet; founding-partner note where relevant.
7. **CTA (50w)** — the Calculator, with the one-minute framing.

**SEO notes:**
- Title tag + H1 contain the primary keyword.
- One keyword per article; don't stuff.
- Internal link to `/calculator` and `/how-it-works`.
- Meta description = the hook, ~150 characters.

## 6. TEMPLATE — Email Newsletter Section (120–200 words)

> Use [`../templates/EMAIL_NEWSLETTER_TEMPLATE.md`](../templates/EMAIL_NEWSLETTER_TEMPLATE.md). Keep it founder-voiced and personal — like a note, not a broadcast.

**Structure:**
- **Subject line** — the hook, curiosity-framed (e.g., "The 7:42pm call you never knew you missed").
- **Opening line** — speak to one person ("Quick one this week —").
- **The idea (100w)** — the video's core message in plain prose.
- **The takeaway (1 line)** — what to do or notice.
- **One CTA button** — "See your number" or "Watch the 60-second version."

**Cadence:** One email per week, built from that week's strongest source video. Never more than one CTA.

## 7. The Repurposing Workflow (step by step)

For each approved source video:

1. **Confirm the core message and funnel stage** (already defined in the production package).
2. **Publish the three native short-form cuts** (IG Reel, TikTok, YT Short) using the captions/descriptions already in the package. Re-upload clean to each — no cross-watermarks.
3. **Publish the LinkedIn post** using the package's LinkedIn adaptation (attach the video natively if it suits the platform).
4. **Build the carousel** from §4 and schedule it 2–3 days after the video (reinforcement, not same-day duplication).
5. **Write the blog** from §5; publish to the site's blog/resources area; this becomes the evergreen link.
6. **Drop one section into the weekly email** from §6, linking to the video or blog.
7. **Run every asset through the [approval checklist](../checklists/CONTENT_APPROVAL_CHECKLIST.md).**
8. **Log each derivative** in the content tracker (see [`CONTENT_OPERATING_SYSTEM.md`](CONTENT_OPERATING_SYSTEM.md)) with UTM tags so performance ties back to the source idea.

**Spacing:** Don't dump all 7 assets the same hour. A healthy rhythm: video Day 0 (all 3 platforms + LinkedIn), carousel Day +2, blog Day +3, email at week's end. The same message, met in different places, builds recognition.
