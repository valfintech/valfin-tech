# Valfin Tech — Content Department
**The complete content operating system for a Revenue Operations Infrastructure company.**

This folder is Valfin's content department in a box. It is designed so that one person — or one AI system with light human oversight — can run a premium, consistent, outcome-first content engine across Instagram Reels, TikTok, LinkedIn, and YouTube Shorts.

> **Read first, always:** [`docs/CONTENT_BRAND_GUIDELINES.md`](../docs/CONTENT_BRAND_GUIDELINES.md) — the rulebook that governs every piece of content. It is downstream of [`docs/VALFIN_FOUNDER_OPERATING_MANUAL.md`](../docs/VALFIN_FOUNDER_OPERATING_MANUAL.md), which is the single source of truth for the business. If anything here conflicts with the Operating Manual, the Operating Manual wins.

## The 30-second mental model

1. **Ideas** live in `ideas/`. They are cheap and plentiful (100 to start).
2. An idea gets **approved** and turned into a **production package** in `production/` — the complete shoot-and-post kit.
3. The finished video gets **repurposed** via `systems/REPURPOSING_SYSTEM.md` into LinkedIn posts, carousels, blogs, emails, and platform descriptions.
4. Everything flows through the **operating system** in `systems/CONTENT_OPERATING_SYSTEM.md` (idea → approval → script → assets → produce → repurpose → schedule → publish → track → optimize).
5. Over time, the **automation blueprint** in `systems/AUTOMATION_BLUEPRINT.md` removes 80–90% of the manual work.

## The non-negotiables (memorize these)

- **We sell outcomes, not AI.** Never lead with the technology.
- **"This was never a marketing problem."** We recover existing leads — we do not generate new ones.
- **Show numbers, not adjectives.** Never invent a statistic or a case study.
- **Plain language, ~8th-grade level.** Write for a busy roofer, not a CTO.
- **One idea, one CTA, per piece.**
