# Valfin Tech — Content Idea Database (100 Ideas)
**Version 1.0 | Created 2026-06-13**
**Governed by:** [`docs/CONTENT_BRAND_GUIDELINES.md`](../../docs/CONTENT_BRAND_GUIDELINES.md)

> 100 ready-to-produce content ideas, organized into 12 categories. Every idea is outcome-first, honesty-compliant, and free of banned language. Each idea maps to a content pillar (P1–P5) and a funnel stage. The machine-readable mirror is [`content_ideas.csv`](content_ideas.csv).
>
> **Honesty note:** Any number that appears in a hook below is a **hypothetical worked example**, never a claimed Valfin result. When produced, it must be framed as "say you get X calls a month…" — never "our clients get…". See Brand Guidelines §7.

**Field key for each idea:**
- **Hook** — the first 1–2 seconds / first line
- **Objective** — what this piece is for
- **Platform** — recommended primary platform(s)
- **CTA** — the single ask
- **Response** — the feeling/action we want from the viewer
