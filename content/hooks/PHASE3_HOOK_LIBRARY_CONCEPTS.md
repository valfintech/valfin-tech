**Scope reminder:** This phase does not touch the VLF-001–005 reels or PKG-005/007/008/013/015 carousels from the launch campaign. **Credit estimates** are directional (based on relative model cost tiers and clip length), not pulled from a live price sheet — confirm exact costs in the Higgsfield UI before generating.

## #1 — The Draining Balance Timer
**Confidence: 9/10**

1. **Business insight:** Every hour a lead goes unanswered, real money — not hypothetical money — drains out of the business in real time.
2. **Hook text:** "Your revenue. Right now."
3. **First 1–2 seconds:** A large, clean account-balance number ($14,820.00) sits center-frame on a dark premium dashboard — and immediately starts ticking DOWN, digit by digit, with a soft red glow on each decrement.
4. **Full visual sequence:**
   - 0:00–0:02 — Balance ticks down rapidly: $14,820 → $14,640 → $14,310. A small red label appears: "Missed call — 8 min ago."
   - 0:02–0:05 — Three more red labels stack in fast succession ("Unanswered text — 22 min ago," "No follow-up — Day 3," "Lead went cold"), each triggering another drop in the balance.
   - 0:05–0:08 — The countdown accelerates into a blur, balance crashing toward zero.
   - 0:08–0:11 — Hard cut: the same dashboard, but the balance is now climbing UP in green, each red label flipping to a green checkmark ("Responded in 8 sec," "Follow-up sent," "Booked").
   - 0:11–0:12 — End card: "Stop the leak." / Valfin wordmark.
5. **Why it stops the scroll:** Opens on a number going down — money loss is the single most universally legible "oh no" visual, and the speed/blur escalation creates urgency before any text registers.
6. **Business pain point:** Revenue leakage from missed calls/slow follow-up, made viscerally immediate rather than abstract.
7. **Recommended Higgsfield model:** Cinema Studio Video 3.0 (hero asset — worth the premium render for the cleanest UI typography and smoothest counter motion).
8. **Estimated credit cost:** ~110–140 credits (8–12s, 1080p, premium tier).
9. **Nano Banana improvement:** Yes — generate the exact branded dashboard UI stills (balance card, red/green label states) as reference frames first, so the video model only has to animate transitions, not invent UI from scratch.
10. **Higgsfield-only or Remotion expansion:** Strong candidate to later rebuild as a full Remotion reel (it already mirrors the VLF-004 calculator visual language) — but ship as Higgsfield-only first to test performance.
11. **Confidence score:** 9/10
